Hướng dẫn cài đặt & sử dụng

  1. 1
    Tải file APK

    Nhấn nút Download trên card bạn muốn. File sẽ được tải về thư mục Downloads.

  2. 2
    Cho phép cài đặt từ nguồn không xác định

    Vào Settings → Security → Install unknown apps và cho phép ứng dụng Files hoặc Chrome cài đặt APK.

  3. 3
    Cài đặt APK

    Mở file vừa tải → nhấn Install → chờ 10–30 giây.

  4. 4
    Mở Roblox

    Đăng nhập tài khoản Roblox như bình thường và vào 1 game bất kỳ.

  5. 5
    Mở Executor & Attach

    Mở app executor → nhấn Attach → chọn Roblox process.

  6. 6
    Dán script & Execute

    Copy script → Paste vào ô editor → nhấn Execute.

  1. 1
    Tải file ZIP/EXE

    Nhấn Download trên card executor PC. File về thư mục Downloads.

  2. 2
    Giải nén (nếu là ZIP)

    Dùng 7-Zip hoặc WinRAR để giải nén ra thư mục riêng.

  3. 3
    Tắt antivirus tạm thời

    Windows Defender có thể báo nhầm. Thêm file vào whitelist hoặc tắt tạm thời.

  4. 4
    Chạy file .exe với quyền Admin

    Right-click file .exe → Run as administrator.

  5. 5
    Mở Roblox & vào game

    Vào 1 game bất kỳ trên Roblox PC.

  6. 6
    Attach & Execute

    Nhấn Attach trong executor → chọn Roblox → dán script → Execute.

Executor không attach được?

Chạy executor với quyền Admin. Tắt antivirus tạm thời. Đảm bảo Roblox đang mở.

Antivirus báo virus?

False positive — executor thường bị nhận nhầm. Thêm file vào whitelist.

Roblox bị crash sau khi inject?

Cập nhật executor lên bản mới nhất. Nếu vẫn lỗi, đổi executor khác.

Có bị ban tài khoản không?

Có thể. Khuyến nghị dùng tài khoản phụ (alt) để test script trước.

⚠️ Sử dụng executor có thể vi phạm ToS của Roblox. Tự chịu rủi ro.
